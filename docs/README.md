# Track — трекер привычек

Личный трекер на `track.diabal.ru`.

## Экраны

1. **Сегодня** — прогресс дня и пункты по времени (еда, работа, режим).
2. **Календарь** — месяц с точками по блокам; клик открывает день.
3. **Статистика** — стрик, % за 7/30 дней по блокам.

## Привычки

| Блок | Что отмечать |
|------|----------------|
| Еда | завтрак, обед, ужин |
| Работа 350к | будни: 1ч вопросы + 1ч лайфкодинг; пт +2ч поиск; выходные: 2ч + 2ч |
| Режим | зарядка + отбой до 22:00 |

Данные хранятся в `localStorage` браузера (`track.habits.v1`).

## Деплой

GitHub Actions: push в `main` → SCP в `/var/www/track.diabal.ru` → nginx + certbot.

Секреты репозитория (как у `health` / zal):

- `SERVER_HOST`
- `SERVER_USERNAME`
- `SERVER_PORT`
- `SSH_PRIVATE_KEY`
