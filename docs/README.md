# Track — трекер привычек

Личный трекер на `track.diabal.ru`.

## Экраны

1. **Сегодня** — прогресс дня и пункты по времени (еда, работа, режим).
2. **Календарь** — месяц с точками по блокам; клик открывает день.
3. **Статистика** — стрик, % за 7/30 дней по блокам.

## Привычки

| Блок | Что отмечать |
|------|----------------|
| Еда | завтрак, обед, ужин |
| Работа 350к | будни: вопросы + лайфкод по 1ч; выходные: 2×вопросы + 2×лайфкод (4ч) |
| Режим | зарядка + отбой до 22:00 |

## Хранение

Данные в SQLite на сервере (`/var/lib/track/track.db`), API `track-api` (pm2, порт `3010`).

Вход по PIN (по умолчанию `111`, env `TRACK_PIN`). PIN хранится в браузере как токен; галочки синхронизируются между устройствами.

Старый `localStorage` один раз мигрирует в базу при первом входе, если сервер пустой.

## Деплой

GitHub Actions: push в `main` → SCP статики + `server/` → `npm install` → pm2 → nginx `/api/` → certbot.

Секреты репозитория:

- `SERVER_HOST`
- `SERVER_USERNAME`
- `SERVER_PORT`
- `SSH_PRIVATE_KEY`
